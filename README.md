# 三级库合作伙伴评估体系 - 每日简报

## 项目说明

每天下午 5:00 自动从「WB-三级库合作伙伴评估体系」智能表格获取最新数据，生成每日简报 HTML。

## 文件结构

```
├── generate_daily_briefing.py   # 简报生成脚本
├── partner_daily_briefing.html  # 每日简报（自动更新）
├── daily_data.json              # 数据快照（用于对比变化）
├── .codebuddy/
│   └── workflow.yml             # CI 定时流水线配置
├── archive/                     # 历史简报归档
└── logs/                        # 运行日志
```

## 简报内容

- 📊 数据总览（合作伙伴数、评估完成数、项目数）
- 📝 入库前能力评估状态
- 🔧 售中支撑记录评估
- ⚠️ 预警与建议

## 数据来源

- WB-三级库合作伙伴评估体系 智能表格 (ID: QwBeLNOgcHHF)

## 运行方式

- **自动**: 工作日下午 5:00 CI 定时触发
- **手动**: 在工蜂 CI 页面点击「手动触发」
